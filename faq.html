Are the rewards real?

No. This is a reward-themed prototype. It does not issue rewards, subscriptions, accounts, or redeemable codes.

Does the site verify a code?

No. Selecting a category records a demo event only. The optional sample label is not sent to the database.

What information is stored?

The demo API stores the selected allowed category and a timestamp. It does not intentionally store the sample label or collect IP addresses in the application code.

Should I enter my password or Discord token?

No. Never enter passwords, payment details, one-time codes, session cookies, or bot tokens into a demo website.

Why did saving a demo event fail?

The database connection may not be configured or the service may be temporarily unavailable. You can still browse the pages; no reward is issued.

Can I contact support for an actual redemption?

This prototype does not provide real redemptions or provider support. The contact form is a visual preview and does not send or save messages.
